## Study Characteristics

| Characteristic | Value |
|---|---|
| Patients (N) | 292 |
| Samples (N) | 584 clips |
| Patients vs. Samples | Yes — pseudoreplication risk (multiple observations per patient treated as independent) |

| Baseline Comparison | No comparator |
| Demographics Disclosed | Disclosed: None / Not reported: age, sex/gender, race/ethnicity, comorbidities |
| Confidence Intervals | Yes, metrics with CIs: Vessel Precision, Vessel Recall, Vessel Classification for Veins, Vessel Classification for Arteries, Average Depth Error, Average Diameter Error |
