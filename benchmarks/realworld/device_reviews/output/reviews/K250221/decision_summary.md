# FDA Decision Summary: Study Characteristics

**Device:** StrokeSENS ASPECTS Software Application (K250221)  

---

## Study Characteristics

| Characteristic | Value |
|---|---|
| Patients (N) | Standalone: 200; Clinical Validation: 100 |
| Samples (N) | Same as patients |
| Patients vs. Samples | N/A — one observation per patient |
| Multi-site | Yes, 23 sites (Canada, United States) |
| Baseline Comparison | StrokeSENS ASPECTS provides a comparative analysis to the ASPECTS standard of care radiologist assessment by providing highlighted ASPECTS regions and an automated editable ASPECTS score for clinician review. |
| Demographics Disclosed | Disclosed: age, sex/gender / Not reported: race/ethnicity, comorbidities |
| Confidence Intervals | Yes, metrics with CIs: AUC-ROC, accuracy, sensitivity, specificity |
| Women's Health | No — the device is related to brain tissue abnormalities and ischemic stroke, which are not conditions that predominantly or disproportionately affect women. |
